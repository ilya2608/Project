Transformation Reference — Where does X happen?

Layer Model / Table Reads From Transformations Applied
Notebook All bronze.* Business Central
REST API v2.0
  • OAuth 2.0 client-credentials token acquisition
  • OData page loop (@odata.nextLink) — handles large datasets
  • Spark DataFrame creation from JSON response
  • Append _ingested_at (UTC ISO-8601) and _source_system = 'BusinessCentral'
  • JDBC mode=overwrite write to Fabric Warehouse bronze schema
Bronze bronze.customer BC /customers
  • No field transformation — raw BC payload stored exactly as received
  • Only additions: _ingested_at, _source_system
Bronze bronze.item BC /items
  • No field transformation — raw BC payload
  • Only additions: _ingested_at, _source_system
Bronze bronze.sales_order_header BC /salesOrders
  • No field transformation — raw BC payload
  • Only additions: _ingested_at, _source_system
Bronze bronze.sales_order_line BC /salesOrderLines
  • No field transformation — raw BC payload
  • Only additions: _ingested_at, _source_system
Silver dim_customer bronze.customer
  • trim() applied to every string column
  • COALESCE nulls → empty string defaults for all address / contact fields
  • UPPER(currencyCode), default 'LCY' when null
  • LOWER(email)
  • is_blocked → INT 0/1 derived from blocked IN ('All','Ship','Invoice')
  • creditLimit, balance → DECIMAL(18,2)
  • lastModifiedDateTime → DATETIME2(0)
  • Filter: WHERE id IS NOT NULL
  • Add _dbt_updated_at = GETUTCDATE()
Silver dim_item bronze.item
  • trim() on all strings
  • COALESCE type → 'Inventory', itemCategoryCode → 'UNCATEGORISED', baseUoM → 'PCS'
  • unitPrice, unitCost → DECIMAL(18,4)
  • inventory → DECIMAL(18,4)
  • is_blocked flag → INT 0/1
  • lastModifiedDateTime → DATETIME2(0)
  • Filter: WHERE id IS NOT NULL
Silver fact_sales_order_header bronze.sales_order_header
  • orderDate, postingDate, requestedDeliveryDate → DATE
  • COALESCE(postingDate, orderDate) — fallback when posting date is null
  • UPPER(currencyCode), default 'LCY'
  • All amount columns → DECIMAL(18,2) with COALESCE(x, 0)
  • is_released → INT 0/1 derived from status = 'Released'
  • All ship-to fields COALESCE → ''
  • lastModifiedDateTime → DATETIME2(0)
  • Filter: WHERE id IS NOT NULL
Silver fact_sales_order_line bronze.sales_order_line
  • CAST(sequence AS INT)
  • quantity, unitPrice → DECIMAL(18,4)
  • discountAmount, lineAmount → DECIMAL(18,2)
  • discountPercent, taxPercent → DECIMAL(5,2)
  • Derived: gross_line_amount = quantity × unitPrice
  • Derived: net_line_amount = quantity × unitPrice − discountAmount
  • shipmentDate → DATE
  • Filter: WHERE id IS NOT NULL
Gold gold_sales_daily fact_sales_order_header
fact_sales_order_line
dim_customer
  • 3-way JOIN: header LEFT JOIN line, LEFT JOIN customer
  • GROUP BY order_date · country_code · currency_code · salesperson_code
  • Aggregate: COUNT(DISTINCT order_guid), COUNT(DISTINCT customer_guid)
  • SUM qty, gross_sales, discounts, net_sales, tax
  • Derived: avg_order_value = net_sales / NULLIF(order_count, 0)
Gold gold_customer_performance dim_customer
fact_sales_order_header
fact_sales_order_line
  • Intermediate CTE aggregates order+line by customer_guid + currency_code
  • LEFT JOIN customer ⟕ aggregated block
  • Lifetime totals: total_orders, gross_revenue, net_revenue, total_qty
  • first_order_date, last_order_date, customer_tenure_days
  • Derived: recency_tier — Recent (≤30d) / Active (≤90d) / At Risk (≤180d) / Lapsed
  • Derived: value_tier — High (≥100k) / Mid (≥10k) / Low
  • Derived: avg_order_value, days_since_last_order
Gold gold_product_performance dim_item
fact_sales_order_header
fact_sales_order_line
  • JOIN line + header, then LEFT JOIN item by item_guid
  • Aggregate by item_guid + currency_code
  • Rolling windows (conditional SUM): net_revenue_l30d, net_revenue_l90d, qty_sold_l30d
  • Derived: gross_margin = net_revenue − (unit_cost × total_qty)
  • Derived: gross_margin_pct
  • Derived: avg_discount_pct = total_discounts / gross_revenue × 100
  • Derived: velocity_tier — Fast Moving (>100 qty/30d) / Regular / Slow Moving / No Sales
  • days_since_last_sale
Gold gold_sales_order_flat fact_sales_order_header
fact_sales_order_line
dim_customer
dim_item
  • 4-way JOIN (one row per line): header JOIN line, LEFT JOIN customer, LEFT JOIN item
  • Date part columns: order_year, order_month, order_quarter, order_year_month
  • Derived: line_cost = quantity × unit_cost
  • Derived: line_gross_margin = net_line_amount − line_cost
  • Derived: line_gross_margin_pct
  • Order-level totals repeated per line (enables any slice in Power BI)
  • Carries all customer and item attributes denormalised — no further joins needed

Naming conventions: Bronze tables use camelCase from the BC API payload. Silver models rename to snake_case and add _dbt_updated_at. Gold models further add computed / aggregated columns with no additional renaming.
